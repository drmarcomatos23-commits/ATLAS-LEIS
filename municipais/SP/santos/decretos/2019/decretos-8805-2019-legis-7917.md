# Decreto n.º 8.805, de 19 de dezembro de 2019

DECRETO Nº 8.805
DE 19 DE DEZEMBRO DE 2019

REAJUSTA OS VALORES DA SUBVENÇÃO AUTORIZADA PELA LEI Nº 3.315, DE 08 DE DEZEMBRO DE 2016.

PAULO ALEXANDRE BARBOSA, Prefeito Municipal de Santos, usando das atribuições que lhe são conferidas por lei,

DECRETA:

Art. 1º Ficam reajustados, nos termos do parágrafo único do artigo 8°, da Lei n° 3.315, de 08 de dezembro de 2016, os valores mensais da subvenção às Organizações da Sociedade Civil que prestam atendimento à crianças e adolescentes residentes no Município de Santos nas modalidades Creche, Pré-Escola e/ou Atividade Complementar, conforme os seguintes valores:

|MODALIDADE                                                           |PERÍODO                  |VALORES PER CAPITA MENSAIS            |
|                                                                     |                         |(EM REAIS)                            |
|CRECHE                            |BERÇÁRIO                          |PARCIAL                  |R$ 318,85                             |
|                                  |                                  |INTEGRAL                 |R$ 531,44                             |
|                                  |MATERNAL                          |PARCIAL                  |R$ 264,90                             |
|                                  |                                  |INTEGRAL                 |R$ 441,51                             |
|PRÉ ESCOLA                        |JARDIM / PRÉ                      |PARCIAL                  |R$ 221,50                             |
|                                  |                                  |INTEGRAL                 |R$ 359,94                             |
|ATIVIDADE                         |EDUCAÇÃO INFANTIL                 |PARCIAL                  |R$ 138,42                             |
|COMPLEMENTAR                      |                                  |                         |                                      |
|                                  |ENSINO                            |PARCIAL                  |R$ 187,64                             |
|                                  |FUNDAMENTAL                       |                         |                                      |

Art. 2º Este decreto entra em vigor na data da publicação.

Registre-se e publique–se.
Palácio “José Bonifácio”, em 19 de dezembro de 2019.

PAULO ALEXANDRE BARBOSA
Prefeito Municipal
