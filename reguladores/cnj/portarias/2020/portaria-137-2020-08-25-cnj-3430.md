|  |  |
| --- | --- |
| 58ª Sessão Virtual Extraordinária | Data: 2/9/2020  Início: 14h  Término: 18h |
| 59ª Sessão Virtual Extraordinária | Data: 4/9/2020  Início: 14h  Término: 17h |
| 60ª Sessão Virtual Extraordinária | Data: 9/9/2020  Início: 14h  Término: 18h |

Art. 2º Esta Portaria entra em vigor na data de sua publicação.

Ministro **DIAS TOFFOLI**
