# RICMS - Artigo 477

Capítulo XIII - DAS MICROEMPRESAS E DAS EMPRESAS DE PEQUENO PORTE

|  |  |  |
| --- | --- | --- |
|  |  |  |

CAPÍTULO XIII - DAS MICROEMPRESAS E DAS EMPRESAS DE
PEQUENO PORTE

**Artigo 477 - Revogado** pelo Decreto [52.104](/Paginas/dec52104.aspx),
de 29-08-2007; DOE 30-08-2007.

**Artigo 477 -** Para o cumprimento das obrigações tributárias
relacionadas com o imposto, as microempresas e as empresas de pequeno porte deverão
observar a disciplina constante no Anexo XX deste regulamento.
