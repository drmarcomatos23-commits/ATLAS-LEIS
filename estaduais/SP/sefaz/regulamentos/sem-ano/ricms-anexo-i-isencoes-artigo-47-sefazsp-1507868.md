# RICMS - Anexo I - Isenções - Artigo 47

Livro VI - Dos Anexos

|  |  |  |
| --- | --- | --- |
|  |  |  |

ANEXO I - ISENÇÕES

(isenções a que se refere o artigo 8º deste regulamento)

**Artigo 47** (MICROCOMPUTADOR USADO - DOAÇÃO) -
Saída de microcomputador usado (semi-novo), em decorrência de doação efetuada
diretamente pelo estabelecimento fabricante ou suas filiais, a escola pública especial e
profissionalizante, a associação de portadores de deficiência ou à comunidade carente
(Convênio ICMS-43/99).

NOTA - VIGOROU ATÉ 31-12-2024​

Parágrafo único - Este benefício vigorará até 31 de dezembro de 2024. (Parágrafo
acrescentado pelo Decreto [67.383](/Paginas/Decreto-67383-de-2022.aspx), de 20-12-2022, DOE 21-12-2022; Em vigor em 16 de
janeiro de 2023)
