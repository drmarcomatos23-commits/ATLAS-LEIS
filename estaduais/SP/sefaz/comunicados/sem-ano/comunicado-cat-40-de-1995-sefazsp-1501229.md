# Comunicado CAT 40 de 1995

Comunicado CAT - 40/95, de 29-05-95

Comunicado CAT - 40/95, de 29-05-95

(DOE de 30-05-95)

Informa sobre a distribuição de selo de controle de saída de álcool.

O Coordenador da Administração Tributária, tendo em vista o disposto na Portaria [CAT - 39/95](/Paginas/pcat391995.aspx), de 12-5-95, comunica:

1. A partir de 31-5-95, os Postos Fiscais estarão distribuindo o selo de controle de saída de álcool instituído pela Portaria CAT-39, de 29-5-95.

2. A partir de 1º-6-95, os Postos Fiscais deverão estar distribuindo os demais selos de controle instituídos pela referida portaria, todavia, caso não os tenham ainda disponíveis, poderão ainda distribuir selos de modelo anterior.

3. Durante o mês de junho de 1995, o contribuinte que possuir selos de modelo anterior deverá ainda utiliza-los, até que se esgotem, antes de usar o modelo novo.

4. A partir de 1º-7-95, somente poderá ser usado selo de modelo novo, devendo os de modelo anterior, ainda remanescentes, ser devolvidos selos dos ao Posto Fiscal.
