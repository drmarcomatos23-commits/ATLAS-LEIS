# Comunicado DICAR 56 de 2019

# ​Comunicado DICAR-56, de 02-09-2019

(DOE 03-09-2019) 

Divulga a Tabela Prática para Cálculo dos Juros de Mora
aplicáveis até 30-09-2019 para os débitos de Taxas.

O Diretor de Arrecadação, Cobrança e Recuperação de
Dívida, considerando o disposto no artigo 13, inciso II, da
Lei 15.266, de 26-12-2013, divulga a Tabela Prática para
Cálculo dos Juros de Mora, aplicável às Taxas, anexa a este
comunicado.
